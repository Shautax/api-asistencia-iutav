# Proyecto: API Backend - Asistencia Tecnológico Américo Vespucio
API REST para gestionar la base de datos de asistencia, usuarios y roles.

## Stack Tecnológico
- Entorno: Node.js.
- Framework: Express.js.
- Base de Datos: MySQL (usando el paquete mysql2).

## Reglas
- Usar arquitectura separada (rutas, controladores y configuración de BD).
- Formato de respuesta siempre en JSON.
